ISHWA K - STUDENT PORTFOLIO

FILES
- index.html: website content
- style.css: design and mobile responsive layout
- script.js: mobile navigation and current year
- assets/ishwa-profile.jpg: profile photo (shown in a circular frame)

RUN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Install the "Live Server" extension if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".

EDITING
- Edit text and links in index.html.
- Edit colours, sizes and layout in style.css.
- Replace assets/ishwa-profile.jpg to change the photo. Keep the same filename.
- Save files; Live Server refreshes the browser.

PUBLISHING
This folder is ready to be uploaded to a GitHub repository and published with GitHub Pages.
The site is not publicly hosted yet. You must publish it from your own GitHub account to get a shareable public URL.

CHECK BEFORE SUBMITTING
- Confirm the contact number and email are correct.
- Check all links on phone and laptop.
- Make sure project descriptions match your actual contribution.
- Add certificates/achievements only when you have verified details.
